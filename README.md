# 纯音输入法 (Pure IME)

专为**红米 Note 4（高通 625 + 第三方 AOSP 15 无 GMS）**量身打造的极简离线中英文输入法。

遵循 **“少即是多（Less is more）”** 的设计哲学：去除传统第三方输入法臃肿的皮肤、广告、剪贴板监听、网络同步和表情包商城，仅保留最纯粹、最快速的中英文输入。

---

## 🌟 核心特色

1. **极致轻量（仅 104 KB）**
   - 整个安装包仅 **104 KB**，几乎不占存储。
   - 运行时常驻内存仅约 **8MB**，冷启动瞬时唤起（< 10ms），骁龙 625 纯 A53 芯片上按键 0 延迟。
2. **绝对安全与物理断网**
   - **零网络权限**：代码与清单文件中**没有申请 `INTERNET` 权限**，物理级断网，绝不上传任何按键记录与隐私。
3. **极简中英文双模**
   - **中文拼音**：单字与高频词组秒级匹配，空格一键上屏，候选词支持水平滑动选取。
   - **英文直接输入**：支持 Shift 快速大小写切换。
   - **数字与全角符号**：一键切换数字及常用标点符号。
4. **纯粹深色主题**
   - OLED 纯黑按键设计，夜间不刺眼，大幅降低功耗。

---

## 🛠️ 构建与编译

本项目基于 JDK 21 与 Gradle 构建：

```bash
# 编译 Release 版（含 R8 极限精简与内置签名）
./gradlew assembleRelease
```

输出 APK：`app/build/outputs/apk/release/app-release.apk`

---

## 📦 安装与启用步骤

1. 下载项目中的 `PureIme_v1.0_sd625.apk` 并安装到手机：
   ```bash
   adb install PureIme_v1.0_sd625.apk
   ```
2. 打开桌面的 **“纯音输入法”** 图标：
   - 点击 **第一步**：在系统设置的语言与输入法中开启“纯音输入法”。
   - 点击 **第二步**：切换为当前输入法。
3. 在测试框中即可直接体验毫秒级响应的中英文输入！
